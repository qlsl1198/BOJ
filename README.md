## 📝 문제별 상세 설명

### 🔢 1037번 - 약수
- **알고리즘**: 수학, 정수론
- **핵심 아이디어**: 어떤 수의 진약수들이 주어졌을 때, 그 수는 가장 작은 약수와 가장 큰 약수의 곱이다.
- **시간복잡도**: O(n log n)

### 📊 2108번 - 통계학
- **알고리즘**: 구현, 정렬, 해시맵
- **핵심 아이디어**: 주어진 수들의 산술평균, 중앙값, 최빈값, 범위를 계산
- **시간복잡도**: O(n log n)

### 📚 20920번 - 영단어 암기는 괴로워
- **알고리즘**: 자료구조, 정렬, 해시맵
- **핵심 아이디어**: 단어를 빈도수 → 길이 → 사전순으로 다단계 정렬
- **시간복잡도**: O(n log n)
- **특이사항**: BufferedReader/Writer 사용으로 빠른 입출력 처리

### 👋 25192번 - 인사성 밝은 곰곰이
- **알고리즘**: 자료구조, 해시셋
- **핵심 아이디어**: ENTER가 나올 때마다 중복 체크를 초기화하여 새로운 인사 카운트
- **시간복잡도**: O(n)

### 💃 26069번 - 붙임성 좋은 총총이
- **알고리즘**: 자료구조, 해시셋
- **핵심 아이디어**: 총총이와 만난 사람들이 무지개 댄스를 전파하는 문제
- **시간복잡도**: O(n)

## 🛠️ 사용된 주요 자료구조 및 기법

- **HashMap**: 빈도수 계산, 키-값 매핑
- **HashSet**: 중복 제거, 빠른 검색
- **ArrayList**: 동적 배열, 정렬을 위한 리스트
- **Scanner**: 기본 입력 처리
- **BufferedReader/Writer**: 빠른 입출력 (대용량 데이터)
- **Comparator**: 커스텀 정렬 기준 정의
